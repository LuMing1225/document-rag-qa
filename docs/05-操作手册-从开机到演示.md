# 操作手册 - 从开机到演示

> **环境**：Windows + PowerShell + VSCode。全程不用 bat。

---

## 一、快速开始（推荐 VSCode，F5 启动）

### 1. 用 VSCode 打开项目

```powershell
code E:\shixunXM\工单4\03-长文本版面分析RAG检索系统
```

VSCode 打开后，右下角选 Python 解释器为 `rag_layout`（Python 3.10）。

### 2. 启动 Milvus（Ctrl+Shift+P → Tasks: Run Task → 启动 Milvus）

或直接在 VSCode 终端里跑：

```powershell
docker start milvus-standalone milvus-etcd milvus-minio
```

等3个容器起来（`docker ps` 确认都是 `Up`）。

### 3. F5 启动全栈

按 `F5`，选 **「🔥 全栈启动 (后端+前端)」**。

VSCode 会同时启动：
- 后端 `http://localhost:8563`
- 前端 `http://localhost:8523`

### 4. 打开浏览器

```
http://localhost:8523
```

完事。

> **如果端口被占用**：说明服务已经在跑了，直接开浏览器就行，不用重复启动。查状态：`Ctrl+Shift+P → Tasks: Run Task → 服务状态检查`。

## 二、不用 VSCode？纯 PowerShell 启动

开两个 PowerShell 窗口，都先执行：

```powershell
cd E:\shixunXM\工单4\03-长文本版面分析RAG检索系统
conda activate rag_layout
```

**窗口1 — 后端：**
```powershell
uvicorn backend.main:app --host 0.0.0.0 --port 8563
```

**窗口2 — 前端：**
```powershell
streamlit run frontend/app.py --server.port 8523 --server.headless true
```

Milvus 没起来的话，另开一个窗口：
```powershell
docker start milvus-standalone milvus-etcd milvus-minio
```

## 四、服务状态速查

PowerShell 一行搞定：

```powershell
docker ps --format "{{.Names}} {{.Status}}" | Select-String milvus
Invoke-RestMethod http://localhost:8563/health | ConvertTo-Json
ollama list
```

| 组件 | 地址 | 正常标志 |
|------|------|----------|
| 前端 | http://localhost:8523 | 浏览器能打开 |
| 后端 | http://localhost:8563/health | `status:ok, ollama_status:ok` |
| Milvus | localhost:19530 | `docker ps` 三个容器 Up |
| Ollama | localhost:11434 | `ollama list` 有 bge-m3 + qwen3:8b |

## 五、常见问题

| 现象 | 解决 |
|------|------|
| `Port 8523 is not available` | 前端已经在跑，直接开浏览器 |
| 页面空白 | Ctrl+F5 强制刷新 |
| 问答"未检索到相关内容" | 确认已构建索引（父块数>0），问答页选对知识库 |
| 后端500 | 检查 `docker ps` 和 `ollama list`，重排器会自动降级 |
| 首次问答>30秒 | 正常，首次加载模型慢，后续10-15秒 |
| 杀占用端口的进程 | `netstat -ano \| findstr :8563` 找PID → `taskkill /PID xxxx /F` |
