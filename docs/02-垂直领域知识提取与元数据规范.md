# 垂直领域知识提取与元数据规范

## 1. 母婴护理领域知识分类

母婴护理垂直领域的知识体系可分为四大核心类别，每个类别下再细分二级和三级标签。这种分类体系是元数据标注和检索过滤的基础。

### 1.1 喂养指南（Feeding Guide）

涵盖从新生儿到幼儿期的全部喂养相关知识：

- **母乳喂养**：哺乳姿势、含接技巧、哺乳频次、奶量参考、乳汁分泌、哺乳期饮食
- **配方奶喂养**：冲调方法、奶量计算、消毒要求、常见配方奶类型
- **辅食添加**：添加时机、质地进阶、食材引入顺序、过敏观察、铁强化食品
- **营养计算**：每日热量需求、蛋白质摄入量、维生素补充（维生素D、铁剂）

### 1.2 疾病预案（Disease Protocol）

涵盖常见新生儿和婴幼儿疾病的识别与处理：

- **黄疸管理**：生理性vs病理性黄疸判断、光疗指征、胆红素监测、喂养调整
- **发热处理**：体温分级、退烧药选择（对乙酰氨基酚/布洛芬）、就医指征
- **常见病症**：肠绞痛、湿疹、腹泻、便秘、鹅口疮、尿布疹
- **急救预案**：窒息急救、呛奶处理、高热惊厥、脱水识别

### 1.3 体温监测（Temperature Monitoring）

这是母婴护理中最具特色的结构化知识类型：

- **正常体温范围**：腋温36.5-37.5℃为正常
- **光疗期间监测**：每2小时测一次，保持36.5-37.5℃
- **发热分级**：低热（37.5-38.0℃）、中热（38.1-38.9℃）、高热（≥39.0℃）
- **记录表格**：日期、时间、体温、喂奶量、排便情况、备注

### 1.4 护理操作（Care Operation）

涵盖日常护理SOP和安全规范：

- **日常护理**：沐浴、脐部护理、抚触、换尿布、剪指甲
- **睡眠安全**：仰卧睡眠、床垫选择、室温湿度、睡袋使用
- **用药安全**：禁用药物清单、退烧药剂量计算、外用药使用
- **感染控制**：手卫生、环境消毒、探视管理

## 2. 元数据字段定义和取值规范

### 2.1 核心字段

| 字段名 | 数据类型 | 是否必填 | 取值规范 | 说明 |
|--------|----------|----------|----------|------|
| chunk_id | string | 是 | `{doc_id}_{type}_{seq}`，如`doc001_child_003` | 全局唯一标识 |
| parent_id | string | 子文档必填 | 对应父文档的chunk_id | 父子映射关系 |
| doc_id | string | 是 | 文档级唯一ID | 同一PDF的所有chunk共享 |
| doc_name | string | 是 | PDF文件名 | 如"母婴护理科学喂养与疾病预案指南.pdf" |
| page_number | int | 是 | ≥1的整数 | 1-based页码 |
| heading_path | string | 否 | 用` > `分隔的层级路径 | 如"第一章 > 1.1 母乳喂养的重要性" |
| position_tag | string | 是 | `heading` / `body` / `table` / `list` / `caption` | 文本块在版面中的角色 |
| layout_type | string | 是 | `paragraph` / `table` / `list` / `figure` / `mixed` | 版面元素类型 |
| column | string | 是 | `left` / `right` / `full` | 双栏排版中的栏位 |
| domain_category | string | 是 | 见下方一级分类枚举 | 领域知识分类 |
| sub_category | string | 否 | 见二级分类枚举 | 细分领域标签 |
| tokens | int | 是 | 正整数 | 该chunk的token数量 |
| char_count | int | 是 | 正整数 | 该chunk的字符数 |
| created_at | string | 是 | ISO 8601格式 | 索引构建时间 |

### 2.2 domain_category 枚举值

```
feeding          — 喂养指南
disease          — 疾病预案
temperature      — 体温监测
care             — 护理操作
safety           — 安全提示
emergency        — 紧急处理
vaccine          — 疫苗接种
nutrition        — 营养管理
```

### 2.3 sub_category 二级分类

| domain_category | sub_category 取值 |
|-----------------|-------------------|
| feeding | breastfeeding, formula, complementary, frequency_volume |
| disease | jaundice, fever, eczema, diarrhea, colic, thrush |
| temperature | normal_range, phototherapy, fever_grade |
| care | bathing, umbilical, massage, sleep_safety, medication |
| safety | feeding_myths, sleep_safety, medication_safety |
| emergency | breathing, dehydration, convulsion, bleeding |
| vaccine | schedule, birth_dose, infant_dose, toddler_dose |
| nutrition | iron, vitamin_d, texture_progress |

## 3. 文档解析流程规范

### 3.1 解析流水线

```
PDF文件
  │
  ├─ Step 1: PDF加载 → pdfplumber.open()
  │
  ├─ Step 2: 逐页提取
  │   ├─ 提取文本块（带坐标）
  │   ├─ 提取表格（pdfplumber.extract_tables()）
  │   └─ 提取字体信息（大小、粗细）
  │
  ├─ Step 3: 版面分析
  │   ├─ 双栏检测（x坐标双峰分布）
  │   ├─ 标题层级识别（字体大小梯度）
  │   ├─ 表格区域标记
  │   └─ 阅读顺序重排
  │
  ├─ Step 4: 父子分块
  │   ├─ 按章节边界切分父文档（~1200 tokens）
  │   ├─ 父文档内按语义切分子文档（~300 tokens，50 tokens重叠）
  │   ├─ 表格不切分，独立成块
  │   └─ 建立父子映射关系
  │
  ├─ Step 5: 元数据标注
  │   ├─ 自动标注：page_number, position_tag, layout_type, column
  │   ├─ 规则推断：heading_path（从标题层级树推导）
  │   └─ 分类标注：domain_category / sub_category（基于关键词规则）
  │
  └─ Step 6: 嵌入与索引
      ├─ 子文档 → bge-m3嵌入 → FAISS子向量索引
      └─ 父文档 → 存储在元数据库（SQLite/JSON）
```

### 3.2 文档解析质量标准

- **文本提取完整率**：≥98%（与PDF原文逐页比对）
- **表格结构还原率**：≥95%（行列对应关系正确）
- **双栏阅读顺序正确率**：≥99%（人工抽检10页）
- **标题层级识别准确率**：≥90%（H1/H2/H3分级正确）
- **父子映射完整率**：100%（每个子文档都能找到父文档）

## 4. 质量校验标准

### 4.1 解析后校验

| 校验项 | 方法 | 通过标准 |
|--------|------|----------|
| 文本完整性 | 对比PDF文本提取结果与解析后全文 | 字符级差异<2% |
| 表格完整性 | 检查表格行列数与PDF原始表格一致 | 行列数完全匹配 |
| 父子映射一致性 | 遍历所有子文档，验证parent_id存在 | 100%映射成功 |
| chunk大小分布 | 统计子文档token分布 | 90%在200-400 tokens之间 |
| 重叠正确性 | 检查相邻子文档的重叠区域 | 重叠约50 tokens，内容连续 |
| 元数据完整性 | 检查必填字段无空值 | 100%必填字段非空 |

### 4.2 检索后校验

| 校验项 | 方法 | 通过标准 |
|--------|------|----------|
| 召回率 | 50个标准问答对测试 | Context Recall ≥ 90% |
| 精确率 | 同上 | Context Precision ≥ 88% |
| 表格查询正确率 | 10个表格相关问题 | 正确率≥90% |
| 双栏文档正确率 | 5个双栏相关问题 | 正确率≥95% |

### 4.3 校验流程

1. **自动化校验**：`scripts/build_index.py`构建索引后自动运行校验脚本
2. **抽样人工校验**：每100页PDF抽样5页，人工比对解析结果
3. **回归测试**：`tests/test_layout.py`和`tests/test_chunking.py`确保修改不破坏已有功能
4. **评估闭环**：`tests/run_ragas_eval.py`定期运行Ragas评估，监控指标变化
