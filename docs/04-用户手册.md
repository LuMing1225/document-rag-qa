# 用户手册

## 1. 环境准备

### 1.1 系统要求

- 操作系统：Windows 10/11（64位）
- Python：3.10+（通过Anaconda安装）
- 显存：≥8GB（推荐RTX 3060及以上）
- 内存：≥16GB（推荐32GB，千万级向量需更多）
- 磁盘：≥20GB可用空间（模型+向量索引）

### 1.2 安装Anaconda

如果尚未安装Anaconda，请从 https://www.anaconda.com/download 下载并安装Windows版本。安装时勾选"Add Anaconda to PATH"选项。

### 1.3 安装Ollama

1. 访问 https://ollama.com/download 下载Windows版Ollama
2. 运行安装程序，默认安装即可
3. 安装完成后，Ollama会在系统托盘运行（图标为小羊驼）

### 1.4 下载Ollama模型

打开命令提示符（CMD），依次执行：

```bash
# 下载嵌入模型（约1.2GB）
ollama pull bge-m3:latest

# 下载生成模型（约4.7GB）
ollama pull qwen3:8b
```

> 注意：模型下载需要较长时间，请确保网络畅通。可以用 `ollama list` 查看已下载的模型。

### 1.5 下载BGE-Reranker

重排模型 `bge-reranker-large` 需要从HuggingFace下载：

```bash
# 方式一：自动下载（首次运行时会自动下载）
# 方式二：手动下载
# 从 https://huggingface.co/BAAI/bge-reranker-large 下载到 models/bge-reranker-large/
```

## 2. 安装步骤

### 2.1 创建Conda环境

打开Anaconda Prompt，执行：

```bash
conda create -n pdfqa python=3.10 -y
conda activate pdfqa
```

### 2.2 安装Python依赖

进入项目目录：

```bash
cd E:\shixunXM\工单4\03-长文本版面分析RAG检索系统
pip install -r requirements.txt
```

主要依赖包括：
- fastapi + uvicorn（后端API）
- streamlit（前端界面）
- pdfplumber（PDF解析）
- faiss-cpu（向量检索）
- sentence-transformers（嵌入模型）
- FlagEmbedding（BGE-Reranker）
- ollama（Ollama API客户端）

### 2.3 验证安装

```bash
python -c "import fastapi, pdfplumber, faiss, streamlit; print('All dependencies OK')"
```

## 3. 启动步骤

### 3.1 确保Ollama运行

检查系统托盘是否有Ollama图标。如果没有，手动启动Ollama：

```bash
ollama serve
```

验证模型可用：
```bash
ollama list
# 应该看到 bge-m3:latest 和 qwen3:8b
```

### 3.2 启动后端

打开一个新的命令提示符窗口：

```bash
conda activate pdfqa
cd E:\shixunXM\工单4\03-长文本版面分析RAG检索系统
uvicorn backend.main:app --host 0.0.0.0 --port 8563
```

看到 `Uvicorn running on http://0.0.0.0:8563` 表示后端启动成功。

### 3.3 启动前端

再打开一个新的命令提示符窗口：

```bash
conda activate pdfqa
cd E:\shixunXM\工单4\03-长文本版面分析RAG检索系统
streamlit run frontend/app.py --server.port 8523
```

浏览器会自动打开 http://localhost:8523 。

## 4. 功能使用指南

### 4.1 PDF上传页面

1. 左侧边栏选择"📄 上传PDF"
2. 点击"浏览文件"按钮，选择要上传的PDF文档
3. 等待上传完成，系统会显示文档ID和页数
4. 上传成功后，可以在"版面分析"页面查看解析结果

### 4.2 版面分析页面

1. 左侧边栏选择"🔍 版面分析"
2. 从下拉框选择已上传的文档
3. 页面显示：
   - 每页的版面布局示意图（标注文本块、表格区域）
   - 双栏检测结果（是否双栏）
   - 识别到的标题层级树
   - 提取的表格内容（Markdown格式）
4. 检查阅读顺序是否正确（特别是双栏文档）

### 4.3 构建知识库索引

1. 左侧边栏选择"📚 知识库管理"
2. 选择要索引的文档
3. 输入知识库名称（如"母婴护理知识库"）
4. 点击"开始构建索引"
5. 等待构建完成，查看报告（父文档数、子文档数、表格数、耗时）

### 4.4 问答页面

1. 左侧边栏选择"💬 智能问答"
2. 从下拉框选择要查询的知识库
3. 在输入框中输入问题，如"新生儿黄疸的光疗阈值是多少？"
4. 点击"发送"或按Enter
5. 系统会显示：
   - AI生成的回答
   - 引用来源（页码、章节路径）
   - 检索耗时和生成耗时
6. 可以继续追问，系统保持上下文对话

### 4.5 支持的问题类型

- **事实查询**："纯母乳喂养建议持续到几个月？"
- **表格查询**："0-1周的新生儿每天喂几次？"
- **流程查询**："辅食添加的原则是什么？"
- **对比查询**："生理性黄疸和病理性黄疸有什么区别？"
- **安全查询**："婴儿睡眠有什么注意事项？"

## 5. 常见问题排查

### 5.1 后端启动失败：端口被占用

```bash
# 查看占用8563端口的进程
netstat -ano | findstr :8563
# 杀掉进程（替换PID）
taskkill /PID <PID> /F
```

### 5.2 前端启动失败：端口被占用

类似地检查8523端口，或换一个端口启动：
```bash
streamlit run frontend/app.py --server.port 8524
```

### 5.3 Ollama模型下载慢

可以设置HuggingFace镜像：
```bash
set OLLAMA_HOST=127.0.0.1:11434
# 或者使用代理
set HTTPS_PROXY=http://127.0.0.1:7890
```

### 5.4 检索结果不相关

1. 检查是否已成功构建索引
2. 尝试在问答页面调整top-k参数
3. 查看"版面分析"页面，确认PDF解析正确
4. 对于表格数据，确保表格没有被错误切分

### 5.5 回答速度慢

- 首次查询会加载模型，较慢（约10-20秒）
- 后续查询应该在2-5秒内
- 如果持续很慢，检查GPU是否正常工作：
  ```bash
  nvidia-smi
  ```
- 确认Ollama使用GPU推理：
  ```bash
  ollama run qwen3:8b "你好"
  # 看输出中是否有 GPU 字样
  ```

### 5.6 显存不足（OOM）

1. 关闭其他占用GPU的程序
2. 在Ollama中设置限制：
   ```bash
   set OLLAMA_NUM_GPU=20
   ```
3. 减小嵌入batch_size
4. Reranker可以设置为CPU模式运行

### 5.7 中文乱码

确保终端使用UTF-8编码：
```bash
chcp 65001
```
